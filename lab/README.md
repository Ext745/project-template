# lab/ — Raw exploration

> ⚠️ **Unverified.** Nothing in here has been tested on hardware unless its NOTES.md says so. Don't build from it without your own review, especially anything involving high voltage, RF power, or stored energy.

This folder holds the honest record of how the project actually developed: experiments, alternative approaches, raw AI output, and dead ends. It's kept on purpose. The failures are part of the work.

## Layout
One folder per attempt: `lab/<YYYY-MM-DD>-<topic>/`, each containing a `NOTES.md`:

```markdown
# <Topic>
**Date:** · **By:** human | agent | both · **Outcome:** promoted | abandoned | parked

## What was tried
## What happened
## Why it was promoted / abandoned
## Pointers
<Commit, decision record, or main-path code it became.>
```
